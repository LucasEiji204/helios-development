## ✨ Funcionalidades

- Página inicial com animações feitas em **Framer Motion**
- Páginas de **Institucional**, **Soluções**, **Projetos**, **Tecnologia**, **Sustentabilidade**, **Conteúdos** e **Carreiras**
- Formulário de **Contato**
- Páginas de **Privacidade** e **Termos de uso**
- SEO com `sitemap` e `robots` gerados pelo Next.js
- Layout responsivo com **Tailwind CSS**

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| Next.js (App Router) | Estrutura, rotas e renderização |
| React | Componentes da interface |
| TypeScript | Tipagem do código |
| Tailwind CSS | Estilização e responsividade |
| Framer Motion | Animações e transições |

## 📁 Estrutura do repositório

```
helios-development/
├── website/                          # Aplicação Next.js (código do site)
│   └── src/
│       ├── app/                      # Páginas e rotas
│       ├── components/               # Componentes (layout, animações, formulários, UI)
│       ├── data/                     # Conteúdo das páginas
│       └── lib/                      # Funções utilitárias
├── helios_development_home/          # Protótipo da página inicial
├── helios_institutional/             # Protótipo da página institucional
├── institucional_helios_development/ # Protótipo institucional (variação)
├── nossa_hist_ria_helios_development/# Protótipo da página "Nossa história"
└── solu_es_helios_development/       # Protótipo da página de soluções
```

## ▶️ Como executar

```bash
# Clone o repositório
git clone https://github.com/LucasEiji204/helios-development.git

# Entre na pasta do site
cd helios-development/website

# Instale as dependências
npm install

# Rode em modo de desenvolvimento
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000) no navegador.
